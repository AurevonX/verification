# نظام التحقق من الوثائق

نظام بسيط للتحقق من صحة الوثائق عبر رابط يحتوي على كود تحقق.

## 🚀 طريقة الإعداد

1. رفع جميع الملفات إلى مستودع GitHub.
2. تفعيل GitHub Pages من الإعدادات.
3. استخدام الرابط التالي للتحقق:
   `https://[username].github.io/[repository]/index.html?v=[CODE]`

## 📝 إضافة وثيقة جديدة

1. افتح ملف `data.json`.
2. أضف عنصرًا جديدًا بالصيغة التالية:
   ```json
   {
     "code": "كود_تحقق_طويل",
     "id": "رقم_الوثيقة",
     "date": "تاريخ_الإصدار"
   }
   ```
3. احفظ الملف وارفع التعديلات إلى GitHub.

## 🔧 استخدام المولد

لفتح `generator.html`، وأدخل رقم الوثيقة وتاريخ الإصدار، ثم انقر على "إنشاء كود التحقق" وانسخ النتيجة وألصقها في `data.json`.

- الصفحات متجاوبة مع جميع الأجهزة.
